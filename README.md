# 星穹铁道探索与常驻活动 Skills

供 Codex 使用的两个技能包，复用三月七小助手的观察、输入、路线和战斗能力，按游戏内实际进度核验结果。

| 技能 | 用途 |
| --- | --- |
| [treasure-opening ZIP](treasure-opening.zip) | 指定区域宝箱与特殊寻宝目标：地图定位、路线移动、交互与收集核验。路线跑完不等于全图收集完成。 |
| [star-rail-permanent-events ZIP](star-rail-permanent-events.zip) | 常驻活动、常时传略与往期活动：入口定位、剧情与玩法推进、领奖及完成核验。纯日常清体力使用三月七小助手技能。 |

## 安装

下载上表中的 ZIP，解压后将对应同名文件夹放到 Codex 的技能目录 `~/.codex/skills/`。确保 `SKILL.md` 位于同名文件夹内，避免重复嵌套目录，并保留 ZIP 内的 `references/`、`scripts/` 等配套文件。

两个技能可以分别安装；活动涉及探索时会复用宝箱技能，建议一起安装。

## 运行依赖

- 需要安装并配置 `march7th-assistant` 技能，以及可运行的 Windows 游戏环境和适配的三月七小助手源码环境。[三月七小助手上游仓库](https://github.com/moesnow/March7thAssistant)。本仓库不包含该依赖技能或完整游戏自动化运行环境。
- 使用源码环境已有的 Python 和依赖。技能引用的地图定位、路线、OCR 及控制能力以实际源码版本为准；源码中的新能力不保证上游已发布安装版已有。
- 活动技能 ZIP 内的控制脚本依赖三月七小助手仓库及其运行环境，不是可独立执行的程序。具体启动方式见 ZIP 内的 `references/session-control.md`。
- 活动控制会话的点击、拖动和 OCR 区域使用返回画面的 **1920×1080 归一化坐标**；更换画面布局或地图标定后需重新确认位置。出现真实 Windows UAC 提示时，由用户人工确认。

## 用法示例

安装后在 Codex 中说明目标与范围，例如：

```text
使用 treasure-opening，收集我当前区域剩余的普通宝箱，以地图计数核验。

使用 star-rail-permanent-events，继续当前常时传略活动，完成主流程和常驻奖励领取。

使用 star-rail-permanent-events，只完成这个活动的剧情，保留可观看的剧情，不扩展到全收集。
```

开始前保持游戏可捕获，并避免多个程序同时控制游戏。中断后先确认当前任务和游戏状态再续跑；最终以游戏内目标、计数和奖励状态判断完成。
